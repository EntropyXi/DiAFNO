# diafno

日尺度 SST 的数据、模型、训练、验证和推理核心包。
本层文件用途见下方；子目录详见各自 README。实验产物保持原路径；本次不改变训练或评估行为。

## 本层项目树

```text
diafno/
├── data/  # HDF5 样本读取与输入数据契约
├── evaluation/  # 在线验证、离线评估、配对统计与对比图
├── inference/  # 批量推理、权重加载与预测文件保存
├── models/  # IAFNO 骨干、EDM 扩散与模型配置
├── training/  # 训练配置、数据加载、训练循环和权重保存
├── __init__.py  # 声明该 Python 包并组织其公共接口
└── README.md  # 说明本目录用途并列出本层文件和子目录
```
